# Roadmap

| Phase | Scope | Goal | Exit check |
|---|---|---|---|
| 0 (2-3 weeks) | Talk to 10 GeM sellers or bid consultants. Prepare 3-5 bids by hand with AI help | Prove people will pay | 3 users agree to pay |
| 1 (6-8 weeks) | Profile via GSTIN/Udyam, GeM discovery, document pipeline, cited requirements, rule-based score, vault with expiry, dashboard, audit log, WhatsApp alerts | Free hook, extraction accuracy | Recall 95% on mandatory items |
| 2 | Missing-document workflow, compliance matrix, declarations, reminders | First paid plan | 20 paying users |
| 3 | Technical bid and covering letter generation, reuse from past bids, approval workflow | Core "AI employee" value | Users send bids prepared here |
| 4 | CPPP and 1-2 state portals, pricing intelligence, consultant multi-client workspace | Scale | 100+ tenants |
| 5 | Assisted submission via local agent or extension, DSC aware | Time saving at the last step | Only after trust is established |

## Rules for the roadmap

- Pick one vertical first (for example electrical or IT hardware).
- Do not build more portal adapters until extraction quality is proven.
- Start collecting award prices and bid outcomes in Phase 1, even before using them.
- Auto-submission stays off until Phase 5.

## Later ideas

Win-probability from outcome data, buyer behavior insights, regional-language support, tender consortium matching, mobile app.
